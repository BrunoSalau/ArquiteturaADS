2 estilos -> Monolitico, Cliente-Servidor

Definição: 

    -> Monolitico: O estilo monolitico se baseia em concentrar seu sistema em apenas uma aplicação, fazendo todas suas funções sem precisar de um micro-serviço

    -> Cliente-Servidor: O estilo cliente-servidor é quando você possui um sitema e uma plataforma de cliente, aonde fara requisições para seu servidor e recebera respsotas do mesmo

Casos de uso comuns:

    -> Monolitico: Um caso comum do uso do monolitico, é quando voce precisa fazer uma pequena aplicação, sem a necessidade de montar uma arquitetura elaborada para suprir a necessidade.
    Outro caso é quando alguem está aprendendo uma nova linguagem... O fato de você fazer o sistema em monolitco, ajuda a entender a logica da linguagem e suas funcionalidades.

    -> Cliente-Servidor: Um caso muito comum de uso do Cliente-Servidor são sistemas de e-comerces, ja que o mesmo utiliza de um servidor e uma plataforma do cliente, aonde deve haver uma comunicação entre o cliente e o servidor. Outro uso desse estilo são sistemas bancarios, ja que o sistema tem que se comunicar com o banco de dados, lendo, adicionando e excluindo informações.

principais vantagens:

    -> Monolitico: Facilidade de entendimento e praticidade para pequenas aplicações

    -> Cliente-Servidor: Vantagem em arquitetura organizada para comunicação entre cliente e servidor

principais desvantagens:

    -> Monolitico: Possui uma arquitetura desorganizada, e para grandes sistemas é inapropriado

    -> Cliente-Servidor: Necessita de um esforço a mais e um entendimento da linguagem acima da media para não ter dificuldade
